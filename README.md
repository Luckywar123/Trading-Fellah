# Aggressive Sniper Bot v3.0

Bot trading dengan SL TIGHT + Trailing 10 pips setelah 50 pips profit.

## Features
- SL Tight (8-12 pips)
- Trailing: Aktif setelah 50 pips, jarak 10 pips
- AI Exhaustion Detection (exit dini sebelum SL)
- Web Dashboard Real-time
- Backtest Framework
- Forward Test Mode

## Quick Start

1. Install dependencies
2. Isi konfigurasi di `.env`
3. Jalankan bot dengan `python main.py`
