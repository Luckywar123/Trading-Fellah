CARA PAKAI (v2 - revisi)
=========================

Ini revisi dari rar sebelumnya. Ada 2 bug yang dibenerin:
1. .vercelignore kemarin bisa ikut ngehapus frontend/src/ (source code
   React kamu) — sekarang semua pattern-nya di-anchor ke root pakai "/"
   di depan, jadi cuma kena folder/file di ROOT repo aja.
2. vercel.json sekarang ditaruh DI DALAM folder frontend/, bukan di
   root lagi — soalnya Root Directory project kamu di Vercel dashboard
   kelihatannya udah ke-set ke "frontend".

LANGKAH:

1. Buka Vercel dashboard -> project Trading-Fellah -> Settings ->
   General -> cek "Root Directory". PASTIKAN isinya "frontend"
   (kalau belum, set ke "frontend" terus Save).

2. HAPUS vercel.json yang lama di ROOT repo kamu (dari rar sebelumnya).
   git rm vercel.json

3. Extract rar ini, lalu copy:
   - frontend/vercel.json  -> masuk ke folder frontend/ project kamu
     (timpa kalau udah ada)
   - .vercelignore         -> tetap di ROOT project kamu (timpa yang lama)

   Struktur akhirnya:
   Trading-Fellah/
   |-- .vercelignore        <- dari rar ini (versi baru)
   |-- backend/
   |-- frontend/
   |   `-- vercel.json      <- dari rar ini (lokasi baru)
   |-- docker-compose.yml
   `-- ...

4. Commit & push:
   git add -A
   git commit -m "fix: move vercel.json into frontend/, anchor vercelignore to root"
   git push

5. Redeploy. Karena Root Directory udah "frontend", Vercel otomatis
   jalanin npm install & vite build di dalam folder itu tanpa perlu
   custom buildCommand lagi — jadi gak ada lagi "cd frontend" dobel.

6. Isi env var VITE_API_URL di Vercel project settings dengan URL
   backend kamu (dari Railway/Render).
